## Replacing or adding images

- **Tellers**: Admin → 占い師管理 → upload a photo. It replaces the silhouette.
- **Chatbot guide**: Admin → サイト設定 → 案内係の画像.
- **Campaign banners**: Admin → トップバナー.
- **News and column covers**: Admin → 記事 → カバー画像.
- **Page headers and section photos**: replace the file in `public/images/photos`, keeping the same file name.
